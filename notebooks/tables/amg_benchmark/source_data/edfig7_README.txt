Source Data Extended Data Figure 7

edfig7A_all_tier_upset_by_sequence_source.csv (Extended Data Figure 7). One row per combination of sequence source and membership in the 12 sets of the figure, 161 rows covering the 49,911 genes called at one of the three primary tiers, which form 63 intersections. Sources: Viromes (60 rows, 37,495 genes), Mixed metagenomes (52 rows, 10,580 genes) and Viral genomes (49 rows, 1,836 genes). The sets are the nine tiers of Figure 3 and three further DRAM-V configurations. Tiers are cumulative, so each tier includes the calls of the stricter tiers of the same tool and a gene is TRUE in every set that contains it. DRAM-V (aux 1), (aux 2) and (aux 3) hold the calls of the default DRAM-V configuration at auxiliary score 1, at most 2 and at most 3, and DRAM-V (allow T), (aux 4) and (aux 4, allow T) are full configurations that include the default calls. Columns: source, one Boolean column per set (CheckAMG (high), CheckAMG (medium), CheckAMG (low), DRAM-V (aux 1), DRAM-V (aux 2), DRAM-V (aux 3), DRAM-V (allow T), DRAM-V (aux 4), DRAM-V (aux 4, allow T), VIBRANT (high), VIBRANT (medium), VIBRANT (low)), n_calls. Set sizes from this file count genes within the 49,911, so they differ from the tier totals of Extended Data Figure 5A for the lower tiers (for example 14,644 for CheckAMG (low) against 170,161).
